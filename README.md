# Adventure Time: Pirates of the Enchiridion — Tradução PT-BR para PC

Port não oficial para PC da tradução brasileira de **Adventure Time: Pirates of the Enchiridion**.

> **A tradução original foi feita pela [MILTRADUÇÕES](https://www.miltraducoes.com/post/tradu%C3%A7%C3%A3o-pt-br-do-jogo-adventure-time-pirates-of-the-enchiridion) para Nintendo Switch.**
>
> Este projeto apenas adapta a tradução para funcionar na versão de PC.

## 📥 Download

Baixe a versão mais recente na página de **Releases** deste repositório.

A tradução acompanha um launcher simples que:

* localiza automaticamente a instalação do jogo pela Steam;
* permite selecionar manualmente a pasta do jogo;
* instala a tradução;
* cria um backup automático do arquivo original;
* permite restaurar o jogo ao estado original.

## 🔧 Instalação

1. Baixe o `.zip` da versão mais recente em **Releases**.
2. Extraia os arquivos.
3. Execute:

```text
Launcher_PTBR_Hora_de_Aventura.exe
```

4. O launcher tentará encontrar o jogo automaticamente.

Caso não encontre, clique no botão `...` e selecione uma destas pastas:

```text
Adventure Time Pirates of the Enchiridion
```

ou:

```text
Adventure Time Pirates of the Enchiridion_Data
```

ou:

```text
Adventure Time Pirates of the Enchiridion_Data\Managed
```

5. Clique em **INSTALAR**.
6. Abra o jogo normalmente pela Steam.
7. Deixe o idioma do jogo configurado como **INGLÊS**.

A tradução utiliza a localização inglesa do jogo para exibir os textos em português.

## 💾 Backup e restauração

Antes de modificar o jogo, o launcher cria automaticamente:

```text
Assembly-CSharp.original.backup.dll
```

O backup não é sobrescrito caso já exista um arquivo original válido.

Para remover a tradução, abra o launcher novamente e clique em:

```text
RESTAURAR
```

Também é possível restaurar os arquivos originais usando a opção **Verificar integridade dos arquivos** da Steam.

## 🛡️ Sobre o aviso do Windows

O launcher não possui certificado digital, então o **Windows SmartScreen pode exibir um aviso** ao executá-lo.

O launcher:

* não acessa a internet;
* não baixa arquivos;
* não executa comandos externos;
* contém a tradução embutida;
* modifica somente o arquivo necessário do jogo;
* verifica os arquivos antes da instalação;
* cria um backup antes de qualquer substituição.

O código-fonte do launcher está disponível neste repositório para consulta.

## 🔍 Código-fonte

O launcher foi desenvolvido em **Go**, utilizando APIs nativas do Windows.

O projeto não depende de bibliotecas externas para realizar a instalação da tradução.
